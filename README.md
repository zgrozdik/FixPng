# PNG Repair Tool

Инструменты для восстановления и обработки PNG файлов.

## 📁 Файлы проекта

- `png_repair.py` - основной скрипт восстановления PNG файлов
- `batch_repair.py` - пакетная обработка нескольких файлов
- `create_test_files.py` - создание тестовых данных
- `check_results.py` - проверка результатов восстановления
- `generate_report.py` - генерация отчетов
- `visualize_results.py` - визуализация результатов
- `run_tests.py` - запуск всех тестов

## 🚀 Быстрый старт

```bash
python png_repair.py input.png output.png
